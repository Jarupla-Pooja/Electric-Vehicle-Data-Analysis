# 🚗 Electric Vehicle (EV) Data Scraping & Exploratory Data Analysis

## 📌 Project Overview
This project focuses on exploring and analyzing Electric Vehicle (EV) data to understand market trends, vehicle specifications, pricing patterns, battery performance, and driving range. The analysis was performed using Python, statistical techniques, and data visualization.

## 🎯 Objectives
- Collect and explore Electric Vehicle data.
- Clean and preprocess the dataset.
- Analyze brand-wise vehicle distribution.
- Understand the relationship between battery capacity and driving range.
- Explore vehicle pricing and energy consumption patterns.
- Perform correlation analysis and hypothesis testing.
- Extract meaningful insights from the data.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- BeautifulSoup (Web Scraping)
- Jupyter Notebook

## 📂 Dataset Information
- **Source:** EV Database
- **Total Records:** 1,492
- **Total Features:** 14
- **Duplicates Removed:** 1

### Key Features
- Brand
- Model
- Model Year
- Price (Euros)
- Battery Capacity (kWh)
- Driving Range (km)
- Energy Consumption (Wh/km)
- Fast Charging Power (kW)
- Acceleration (0–100 sec)
- Number of Seats
- Vehicle Weight (kg)
- Towing Capacity (kg)
- Cargo Volume (L)
- Charging Stop Range (km)

## 🔍 Project Workflow

1. **Web Scraping:** Collected EV-related information from EV Database.
2. **Data Cleaning:** Handled missing values, duplicates, and data inconsistencies.
3. **Exploratory Data Analysis:** Performed univariate, bivariate, and multivariate analysis.
4. **Data Visualization:** Created charts to identify trends and patterns.
5. **Statistical Analysis:** Applied correlation analysis and hypothesis testing.
6. **Insights:** Identified important relationships between EV specifications.

## 📊 Key Insights
- Volkswagen recorded the highest number of vehicles (140), followed by Mercedes-Benz (138).
- Battery capacity and driving range showed a strong positive correlation (0.885).
- Driving range varied significantly across seating-capacity groups.
- Energy consumption showed a statistically significant difference between the compared battery groups.
- Vehicle specifications and performance indicators revealed useful relationships across EV brands.

## 📈 Conclusion
This project provided insights into the Electric Vehicle market through data scraping, exploratory analysis, visualization, and statistical testing. It helped identify relationships between battery capacity, driving range, energy consumption, and other vehicle specifications.
